**現在の版：第1版（2026年11月20日 施行）**　／　過去の版：[第1版](terms-v1.html)

Silent Comfort（以下「作者」）が配布する World Nadenade（以下「本ギミック」）を利用する方（以下「利用者」）は、この規約に同意したものとみなします。ダウンロード、インポート、または利用を始めた時点で同意となります。

## 第1条（対象）

1. 「本体」：スクリプト、Prefab、エディタ拡張、エディタ拡張が生成する素材（画像・メッシュ・マテリアル・クリック音）、説明書。
2. 「基本音源」：本体と一緒に配布する音声ファイルと、その音色設定（Prefab）。
3. 「本データ」：本体と基本音源の総称。利用者が改変したものも含みます。
4. 本データは、BOOTH および作者の VPM リポジトリ（https://silent-dandy.github.io/vpm/）から無料で配布します。BOOTH の支援版も、内容と規約は無料版と同じです。
5. 本データの著作権その他の権利は作者にあります。この規約は利用を許可するもので、権利を譲るものではありません。

## 第2条（許可すること）

利用者は、次のことを無償で行えます。

1. 本データを VRChat のワールドに組み込み、アップロードして公開すること（Public・Private、PC・Android・iOS を問いません。センシティブな音源を追加した場合は第8条に従います）。
2. 本データを自分のワールドに合わせて調整・改変すること。
3. タブレット、操作パネルその他の3Dモデル・テクスチャ・マテリアルを、別のものに差し替えること。
4. 個人・法人を問わず利用すること。有料イベント、収益化した配信、企業のワールドなど、営利目的の利用を含みます。
5. 本ギミック向けの追加音源を制作し、無償または有償で配布・販売すること（第6条）。
6. ワールド制作を請け負い、依頼者のワールドに本データを組み込むこと。
7. 本ギミックを使ったワールドの様子を撮影し、配信・動画・画像として公開すること。ワールドを訪れた方が撮影・配信する場合も同じです。基本音源の音が含まれて構いません。
8. 基本音源を、本ギミック以外の用途に使うこと（第4条）。

## 第3条（改変・差し替え）

1. 改変したものも本データです。改変の程度にかかわらず、第7条の再配布の禁止が及びます。
2. 差し替えに使う3Dモデル等について、VRChat のワールドに組み込んで公開できるかは、利用者自身がその配布元の規約で確認してください。
3. 本データを含まない差し替え用の3Dモデル等を自作し、本ギミック向けとして無償または有償で配布・販売できます。条件は別紙Aに従ってください。
4. 改変方法の解説（文章・画像・設定値の共有）は自由に公開できます。改変したスクリプトや Prefab そのものは配布できません。
5. 改変・差し替えをしたものの動作について、作者はサポートしません。

## 第4条（基本音源の扱い）

1. 基本音源は、作者が公開している「なでなで・ASMR音ジェネレーター」で波形を一から合成して作ったものです。利用者は、基本音源を本ギミック以外の用途（アバター用ギミック、他のワールドギミック、動画、配信、ゲームなど）にも、個人・法人・営利を問わず無償で使えます。ただし、次のことはできません。
   1. 基本音源を加工せずにそのまま、単体で、または素材集の一部として配布・販売すること。作品やギミックに組み込んだ状態で配布・販売することは構いません。
   2. 基本音源を、自分が作った音源として公開・表示すること。
   3. 基本音源や、基本音源を含む作品を、YouTube の Content ID などの音声照合・権利管理サービスに登録すること。基本音源に独占的な権利があると主張し、他の人に使用の中止や対価を求めること。
2. 同じ設定からは誰でも同じ音を作れるため、基本音源と似た音が他の人に使われることがあります。
3. 利用者がジェネレーターで自分で出力した音の扱いは、この規約ではなく、ジェネレーターの利用規約（https://silent-dandy.github.io/generator/terms.html）に従います。

## 第5条（利用者が用意する音源）

1. 利用者は、自分で用意した音源を音色として本ギミックに追加できます。
2. その音源を VRChat のワールドに組み込み、不特定の訪問者に聞かせることが許可されているかは、利用者自身が確認してください。
3. アバター用のなで音ギミックに付属する音源は、ワールドへの組み込みが禁止されていることが多く、権利者の許可がない限り使えません。
4. 利用者が追加した音源によって生じた問題について、作者は責任を負いません。

## 第6条（追加音源の制作・販売）

本ギミック向けの追加音源パックを制作し、無償または有償で配布・販売できます。事前の連絡は不要です。条件は別紙Aに従ってください。

## 第7条（禁止すること）

1. 本データを、改変の有無や一部・全部を問わず、再配布・販売・貸与すること（第4条で認める基本音源の利用を除きます）。
2. 本データを含む Unity プロジェクト、unitypackage、ワールドのデータを配布・販売すること（販売用ワールドへの同梱を含みます）。配布物には含めず、配布ページを案内してください。
3. アップロードされたワールドから本データを抽出すること、抽出したものを使うこと。
4. 本データ（改変・差し替えをしたものを含む）を、自分が作ったもの、または自分が権利を持つものとして公開・表示すること。
5. 作者がそのワールドや商品を公認・監修しているかのように表示すること。
6. 作者や第三者の名誉・権利を傷つける使い方、嫌がらせを目的とした使い方、法令や VRChat の規約に反する使い方。

共同制作者どうしで作業データを受け渡すことは、全員が配布ページから入手していれば構いません。

## 第8条（センシティブな音源）

1. この条で「センシティブな音源」とは、性的な表現、または暴力的・グロテスクな表現にあたる音源（声や効果音を含みます）をいいます。
2. 本ギミックにセンシティブな音源を追加した場合、そのワールドをパブリックワールド（VRChat 上で公開されたワールド。Community Labs に置かれたものを含みます）で使用しないでください。
3. センシティブな音源を追加した本ギミックは、プライベートワールド（公開していないワールド）で、ワールド制作者の責任のもとで使用できます。その場合も VRChat の規約とコミュニティガイドラインに従ってください。
4. 前項の使用によって生じた問題について、作者は責任を負いません。
5. 本ギミックを組み込むワールド自体の内容は、この条では制限しません。VRChat の規約に従ってください。
6. 公開・非公開を問わず、政治活動・宗教活動、特定の個人や集団への憎悪を広める目的では利用できません。

2. VRChat や SDK の更新によって動かなくなる場合があります。更新への対応は努めますが、約束するものではありません。
3. 動作を確認した環境は説明書に記載します。それ以外の環境での動作は保証しません。

## 第11条（規約の変更・準拠法）

1. 作者は、配布ページで知らせたうえでこの規約を変更できます。変更後に入手・更新した本データ（VPM での更新を含みます）には、新しい規約が適用されます。

## 別紙B　作者が販売する有料追加音源の追加条項

作者が販売する有料の追加音源には、この規約に加えて次を適用します（この規約と違う点は、こちらを優先します）。

1. 利用できる人：購入者本人（ギフトで受け取った方を含みます）。
2. 利用できる範囲：購入者が制作する、または共同制作するワールド。ワールドの数に制限はありません。
3. 共同制作：追加音源のデータを Unity 上で扱う人は、それぞれ購入してください。
4. 制作の請負：請け負った側と依頼者の両方が購入している場合に限り、依頼者のワールドへ組み込めます。
5. 禁止：購入していない人へのデータの受け渡し、ライセンスの譲渡・転売、音声ファイルの取り出しと本ギミック以外での利用、機械学習への利用。
6. 返金：ダウンロード商品のため、購入後の返金には応じられません（不具合は更新で対応します）。
