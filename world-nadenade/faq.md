## 音が鳴らないとき

| 症状 | 確かめること |
|---|---|
| パネルの文字が表示されない・フォントが Missing になる | TMP Essentials のインポートと、tmp-fallback-fonts-jp の Tools メニューの設定を済ませてください（[導入する](setup.html)） |
| Packages に World Nadenade が見当たらない | VCC / ALCOM の Manage Project で World Nadenade が追加されているか確かめてください。BOOTH の自動インストーラーは、インポート後にインストールが終わるまで少し時間がかかります |
| エディタの再生（ClientSim）で鳴らない | ClientSim にはアバターの手のコンタクトが無いため、鳴りません。VR の Build & Test かテスト用のアップロードで確かめてください |
| パネルに「未接続」と出る | そのパネルの `Manager` 欄に WorldNadenade を指定してください |
| 誰がなでても鳴らない | 「なで音を聞く」は、聞きたい本人が自分の端末で ON にする必要があります。入室時に ON にしたい場合は NadeManager の `Start Enabled` をオンにします |
| 自分で自分をなでても鳴らない | 「自分なで」が OFF になっています（初期値は OFF） |
| 他人同士のなでなでが聞こえない | 仕様です。自分が関わる接触だけが鳴ります |
| 音が二重に鳴る | WorldNadenade が2個置かれていないか確かめてください |
| 音色ボタンが出ない・数が合わない | 起動時の Console の `[World Nadenade] Presets N` の数と、警告を確かめてください。無効にした音色と、Palm Clip が無い音色は使われません |
| 手のひらでなでているのに手の甲の音が鳴る | アバターによって手の向きの判定が逆になることがあります。パネルの「手のひらと手の甲を入れ替える」を ON にしてください（なでる側の設定です） |
| 最初になでたときだけ音の出だしが遅れる | AudioClip の **Preload Audio Data** をオンにしてください |
| 少し手が離れただけで音が小さくなる | Voice の VRC Spatial Audio Source の **Near** を 0.2 程度にしてください |
| インスペクターで値を変えても変わらない | 値は起動時に読み込みます。変えたら再ビルドしてください |

デバッグ表示パネル（[操作パネルとタブレット](panel.html)）を置き、NadeManager の `Debug Mode` を ON にすると、判定の様子（接触・速度・音量・手のひら / 手の甲）が見られます。

## 処理負荷について

Quest 2 クラスの端末を想定して作っています。

- 「なで音を聞く」が OFF の間は、頭の判定がすべて無効になり、毎フレームの処理も止まります。
- ON の間も、判定するのは「自分の頭」と「自分から `Near Distance`（2.5m）以内にいる人の頭」だけです。
- 鳴っていない Voice は何も処理しません。音色をいくつ置いても、毎フレームの負荷は変わりません。
- パネルの日本語は VRChat 内蔵のフォントで表示するので、フォントによる容量の増加はありません。

それでも重い場合は、`Use Hand Side` をオフにするか、`Near Distance` と Voices の数を減らしてください。

## 既知の制限

- インポスターやフォールバック表示のアバターでは、標準のコンタクトが無い場合があり、その相手とは反応しないことがあります。
- 手の指のボーンが無いアバターでは、手のひら / 手の甲を判定できず、常に手のひらの音になります。タブレットの指タッチもできません（レーザーかデスクトップ操作になります）。
- 同時に鳴る数（Voices の数）を超えた接触は鳴りません。
- 音色ボタンは、壁の操作パネルもタブレットも 6 個までです。7 個目以降の音色はボタンに出ません。
- タブレットは、なで音が OFF の間は消灯していて音色を選べません。壁のパネルで選ぶか、`Tap To Wake` をオンにしてください。

## よくある質問

### Q. エディタで再生すると、パネルが英語で表示されます。

故障ではありません。ClientSim は表示言語を英語として扱うためです。VRChat では、見ている人の表示言語（日本語・英語）で表示されます。エディタで日本語の表示を確かめたいときは、NadeManager の `Force Language` に `ja` と入れてください（確かめ終わったら空欄に戻します）。詳しくは[表示の言語](panel.html#language)をご覧ください。

### Q. 手持ちのアバター用なで音ギミックの音を入れて使えますか。

その音源の規約によります。アバター用の音源はワールドへの組み込みを禁止しているものが多いので、権利者の許可がない限り使わないでください。World Nadenade には、ワールドで使える基本音源が付属します。

### Q. このギミックを入れたワールドで、配信や動画撮影をしても大丈夫ですか。

基本音源については問題ありません。訪れた人が撮影・配信する場合も同じです。自分で足した音源は、その音源の規約に従ってください。

### Q. 更新はどうやって行いますか。

VCC / ALCOM の **Manage Project** で新しいバージョンを選びます。BOOTH の自動インストーラーで入れた場合も同じです（[導入する](setup.html#update)）。

### Q. 販売するワールドに同梱できますか。

できません。購入者には、[配布ページ](https://silent-comfort.booth.pm/items/9171198)から入手してもらってください。

### Q. 追加音源を作って販売できますか。

できます。[音源を用意する](soundpack.html)の「追加音源パックを作る」をご覧ください。

### Q. 訪れる人のアバターに何か入れてもらう必要はありますか。

ありません。VRChat 標準の手・指のコンタクトを使うので、どのアバターでも（上の制限を除いて）反応します。
