World Nadenade は、VRChat のワールドに置くだけで「頭をなでると音が鳴る」ようにするギミックです。判定と発音をワールド側で行うので、**訪れる人のアバターを改変する必要がなく、Android / Quest の人にも聞こえます。**

## できること

- **鳴るのは自分が関わる接触だけ**：「誰かが自分の頭をなでた」「自分が誰かの頭をなでた」ときに鳴ります。他人同士のなでなでは、関係ない人の端末では鳴りません。
- **聞く人が自分で ON にする**：なで音は、操作パネルで「なで音を聞く」を ON にした人にだけ聞こえます。ON/OFF・音量・自分なで（自分の頭をなでても鳴らす）は、各自の端末だけの設定です。
- **音色はなでる側が選ぶ**：選んだ音色は全員に同期され、なでた人の音色で、なでた側・なでられた側の両方に鳴ります。
- **手の動きに合わせて鳴る**：音はなでている手の位置から鳴り、手の速さで音量が変わります。手のひらと手の甲で別の音にクロスフェードできます。
- **操作は2種類**：壁などに置く操作パネルと、手元に持てるタブレット。どちらで操作しても表示がそろいます。
- **音色を足すのが簡単**：音色は Prefab を1つ置くだけで増やせます。音色ごとに試し聴きができます。

## 動作環境

| 項目 | 内容 |
|---|---|
| VRChat SDK | VRChat SDK - Worlds **3.10.6**（UdonSharp） |
| 必要なパッケージ | TextMesh Pro（TMP Essentials）、[tmp-fallback-fonts-jp](https://github.com/Narazaka/tmp-fallback-fonts-jp)（パネルの日本語表示） |
| プラットフォーム | PC / Android（Quest）。PCVR 同士、PCVR と Quest 単機の組み合わせで動作を確認済み |
| アバター | 改変不要（VRChat 標準の手・指のコンタクトを利用） |

パネルの日本語は VRChat に内蔵のフォントで表示するので、ワールドに日本語フォントを入れる必要はなく、容量も増えません。

## 構成

ワールドに置くものは次のとおりです。

| オブジェクト | 数 | 役割 |
|---|---|---|
| **WorldNadenade** | 1ワールドに1個 | 本体。頭の判定・発音・音色・設定の同期 |
| **NadeControlPanel** | 何枚でも | 壁や手持ちメニューに置く操作パネル |
| **NadeTablet** | 任意・何台でも | 持ち運べるタブレット版の操作パネル（同期なし。1台で全員がそれぞれ使えます） |
| NadeDebugPanel | 任意 | 調整用のデバッグ表示。公開時は自動で隠れます |

```
WorldNadenade
├─ Heads          … 頭の判定（定員ぶん）
├─ Voices         … 発音（同時に鳴る数ぶん。推奨 6）
├─ Presets        … 音色（上から順にボタンに並ぶ）
├─ Preview        … 音色の試し聴き
└─ PlayerPreset   … なでる側の設定（音色・手のひら / 手の甲）の同期
```

エディタ拡張のメニューは、すべて **Tools > Silent Comfort > World Nadenade** にあります。
