---

操作は、壁などに置く **操作パネル（NadeControlPanel）** と、手元に持てる **タブレット（NadeTablet）** の2種類です。どちらも色違いの Prefab を同梱しているので、選んで置くだけで使えます。どれで操作しても全部の表示がそろいます。

どちらも画面を同じ2つに分けています。

| 区分 | 内容 | 効く範囲 |
|---|---|---|
| **聞こえる音** | なで音を聞く（ON/OFF）・自分なで・音量 | 自分の端末だけ |
| **なでる音** | 音色・手のひら / 手の甲・入れ替え | なでた相手にも同じ音が聞こえる（全員に同期） |

## 操作パネル（NadeControlPanel）

横長のパネルです（Scale 1 で 84 × 45 cm）。左の列が「聞こえる音」、右の列が「なでる音」です。

### 置き方

先に、[導入する](setup.html)の tmp-fallback-fonts-jp の設定を済ませておきます。

1. World Nadenade の `Prefabs/ControlPanel` から、使う Prefab を選んで Hierarchy に置きます。

   | Prefab | デザイン | 「使い方」の画面 |
   |---|---|---|
   | `NadeControlPanel_Smoke` | 暗色・どの壁にもなじむ（推奨） | 6項目 |
   | `NadeControlPanel_Paper` | 明るい内装・和室向け | 6項目 |
   | `NadeControlPanel_Smoke_TabletNote` | 暗色 | 6項目＋タブレットの戻し方の一文 |
   | `NadeControlPanel_Paper_TabletNote` | 明るい | 6項目＋タブレットの戻し方の一文 |

   タブレットの置き台を置くワールドでは、`_TabletNote` の付いたほうを選びます。

2. 置いたパネルの **`Manager` 欄に WorldNadenade をドラッグ**します（空のままだと「未接続」と表示されます）。
3. 壁の表面から 2〜3cm 手前に出して置きます。

**大きさを変える**：パネルのルートの Scale を変えます（文字も一緒に小さくなります）。Scale 1 で 84 × 45 cm、0.7 で約 59 × 32 cm です。0.7 より小さくすると、文字が読みにくくなります。

**音色ボタン**：6 個（3列×2段）です。音色が 6 個より少ないときは、余ったボタンが自動で隠れます。7 個目以降の音色はボタンに出ません（[音色（Presets）](presets.html)）。

パネルの文字が正しく表示されないときは、tmp-fallback-fonts-jp が入っていないか、パッケージの Tools メニューの設定がまだです（[導入する](setup.html)）。

### 「使い方」の画面

パネルの「? 使い方」を押すと、パネルの中身が使い方の説明（6項目）に切り替わり、「閉じる」で戻ります。切り替えは押した人の端末だけで、他の人のパネルは変わりません。

説明の文は、シーン上の `HelpPage/Item1〜6` の中の `ItemTitle`・`ItemBody` を書き換えれば変えられます。ワールドごとの案内を足したいときに使ってください。

### 表示が薄くなるボタン

- 「向きで切替 / 手のひらで統一 / 手の甲で統一」は、手のひらと手の甲で別の音が入った音色を選んでいるときだけ押せます。
- 「入れ替え」は、「向きで切替」で、手の甲の音がある音色を選んでいるときだけ押せます。押せないときは説明文が理由に変わります。
- 手のひらと手の甲で別の音が入った音色のボタンには、右上に2つの点の印が付きます。

## タブレット（NadeTablet）

横置きのタブレット（約 28 × 21.5 cm）を持ち運び、**人差し指で画面に触れて**操作します。「聞こえる音」「なでる音」の2つのタブに分かれています。

- 同期なしの Pickup です。**1台置けば、全員がそれぞれ自分の手元で使えます**（動かした位置は他の人には見えません）。何台置いても構いません。
- なで音が ON の間だけ画面が点灯します。ON/OFF と自分なでは、壁の操作パネルで切り替えます。
- 音色ボタンは壁のパネルと同じく 6 個までです。

### 置き方

1. World Nadenade の `Prefabs/Tablet` から、使う Prefab を選んで置きます。名前は `NadeTablet_画面のデザイン_本体の色_置き台` の順です。

   | 部分 | 選べるもの |
   |---|---|
   | 画面のデザイン | `Smoke`（暗色）/ `Paper`（明るい） |
   | 本体の色 | `Gray`（グレー）/ `Sand`（サンド）/ `Blue`（ブルー）/ `Lavender`（ラベンダー） |
   | 置き台 | なし / `CradleWoodLight`（木・明るい）/ `CradleWoodDark`（木・濃い）/ `CradleWhite`（白）/ `CradleSameAsTablet`（本体と同じ色） |

   例：`NadeTablet_Smoke_Gray`（置き台なし）、`NadeTablet_Paper_Sand_CradleWoodLight`

2. タブレットの **`Manager` 欄に WorldNadenade をドラッグ**します。置き台つきの Prefab では、置き台の子の `NadeTablet` にあります。
3. 置き場所へ動かします。置き台つきは、置き台ごと動かして背板の裏を壁の表面に合わせます（床から 1.0〜1.2m 程度が目安）。

### 置き台

タブレットを持ち出して見失ったときに、元の場所へ戻すための置き台です。

- タブレットを持ち上げると、置き台に「タブレットを戻す」ボタンが出ます。押すと、押した人の画面のタブレットだけが置き台に戻ります。
- 置き台の近くで手を離すと、置き台に収まります。リスポーンしたときも自動で戻ります。
- 置き台は **Static にしないでください**。子のタブレットまで Static になると掴めなくなります。
- 置き台を置くワールドでは、壁のパネルを `_TabletNote` の付いたものにすると、使い方の画面に戻し方が出ます。

### 操作

| | VR | デスクトップ |
|---|---|---|
| 持つ・置く | 本体の縁か裏に手を近づけて（約 10cm 以内）グリップ。離すとその場に浮いて止まる | 本体の縁か裏をクリック。もう一度で置く |
| ボタン | 人差し指でタップ | 置いた状態ならクリック。持った状態なら照準を合わせて「使う」 |
| 音量 | スライダーを指でなぞる／－ ＋ をタップ | ドラッグ／－ ＋ をクリック |

- VR では、なでようと手を伸ばしたときに遠くのタブレットを掴まないよう、掴める距離を約 10cm にしています。掴みにくければ `Vr Grab Distance` を 0.15〜0.2 に上げてください。
- VR ではレーザーを無効にしています（指で触ろうとしたときに邪魔になるため）。使いたい場合は `Laser In VR` をオンにします。
- 押す位置が指先とずれるときは `Tip Extrapolation` を調整します。

### 主な設定項目（NadeTabletPanel）

| 項目 | 内容 | 初期値 |
|---|---|---|
| Start Tab | 入室時に開くタブ（0 = 聞こえる音、1 = なでる音） | 0 |
| Volume Step | － / ＋ 1回の変化量 | 0.1 |
| Tip Extrapolation | 指先の推定。押す位置がずれるときに調整 | 1.8 |
| Laser In VR | VR でもレーザーで操作できるようにする | オフ |
| Vr Grab Distance / Desktop Grab Distance | 掴める距離（m） | 0.1 / 2 |
| Use Haptics / Click Volume | 振動の有無 / タップ音の大きさ | オン / 0.6 |
| Tap To Wake | 消灯中にタップしたら、なで音を ON にする（オフなら案内だけ） | オフ |

### 自作のメッシュに差し替える

`Body` のメッシュとマテリアルを差し替え、画面（`Screen`）の位置だけを合わせます。

- `Screen` の Scale と Size は変えないでください（指の判定と寸法がずれます）。
- `OutlineBand` も新しいメッシュの側面に合わせてください。本体全体を縁取りの対象にすると、Android で手の上にタブレットが重なって見えます。
- 掴む範囲の `BoxCollider` の前面は、画面より奥に置いてください。
- 実在の製品の形・ロゴ・名称をまねたメッシュやテクスチャは使わないでください。

## 3D のスイッチにする（NadeSwitch・任意）

パネルではなく、3D のオブジェクトを Interact で押す形にしたいときに使います。

- スイッチに Collider と **NadeSwitch** を付け、`Manager` に WorldNadenade、`Event Name` に `_ToggleSwitch` を指定します。
- `Event Name` を `_NextPreset` にすると、自分の音色を次へ進めるボタンになります。

## デバッグ表示パネル（NadeDebugPanel・任意）

World Nadenade の `Prefabs/Debug` にある `NadeDebugPanel_Smoke` か `NadeDebugPanel_Paper` を置き、`Manager` 欄に WorldNadenade を指定します。全体の状態と、鳴っている音（速度・音量・手のひら / 手の甲の判定）の表を表示します。NadeManager の `Debug Mode` がオフのときは自動で隠れるので、公開時に削除する必要はありません。

## 表示の言語 {#language}

操作パネル・タブレット・置き台の文字は、見ている人の **VRChat の表示言語**に合わせて自動で切り替わります。ワールド制作者が設定することはありません。

- 対応しているのは日本語と英語です。ほかの言語の人には英語で表示されます。
- 表示言語は各自の端末だけのものです。日本語の人と英語の人が同じパネルを見ても、それぞれの言語で表示されます。
- ワールドにいる間に VRChat の言語設定を変えると、その場で切り替わります。
- 音色名は、音色ごとに言語別の名前を付けられます（[音色（Presets）](presets.html)の `Localized Names`）。基本音色には英語名が入っています。
- パネルの文字（「使い方」の画面の説明など）を書き換えた場合、書き換えた文字は翻訳されず、どの言語の人にもそのまま表示されます。
- デバッグ表示パネルは、ワールド制作者向けなので日本語だけです。

### エディタ（ClientSim）では英語で表示されます

> ClientSim は表示言語を英語として扱うため、**エディタで再生するとパネル・タブレットが英語で表示されます。** 故障ではありません。VRChat で表示言語が日本語の人には、日本語で表示されます。

エディタで日本語の表示を確かめたいときは、NadeManager の **Force Language** に `ja` と入れて再生します。確かめ終わったら、**必ず空欄に戻してください。** 入れたままアップロードすると、訪れた全員がその言語に固定されます。
