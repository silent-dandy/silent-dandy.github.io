---
title: 音色（Presets）
description: 音色の追加・並べ替え・調整と、試し聴き、Sound Tuner の使い方です。
---

音色は、WorldNadenade の子 **Presets** の下に置いた **NadeSoundPreset** で管理します。1つのオブジェクトに「名前・手のひらの音・手の甲の音・音の出方」がまとまっているので、**音色を足すときはオブジェクト（または Prefab）を1つ置くだけ**です。

```
WorldNadenade
└─ Presets
    ├─ Normal     … 先頭 = 入室したときの音色
    ├─ Oil
    └─ …
```

- 上から順に、音色ボタンに並びます。**先頭の音色が、入室したときの音色**になります。
- **無効にした音色は使われません。** 一時的に外したいときは、削除せずに無効にできます。
- 並べ替え・途中への追加・削除をしても構いません（音色は Preset Id で見分けます）。
- 音色ボタンは、壁の操作パネルもタブレットも **6 個まで**です。7 個目以降の音色はボタンに出ないので、使う音色を 6 個までにしてください（使わない音色は無効にします）。

## 音色を足す

### ツールで作る（おすすめ）

1. Project ウィンドウで、音色にしたい **AudioClip（手のひらの音）を選びます**。複数選べます。
2. **Tools > Silent Comfort > World Nadenade > Add Sound Preset** を実行します。
   - 1クリップにつき1つ、Presets の末尾に音色ができます。表示名・手のひらの音・Preset Id はクリップ名から設定されます。
3. できた音色の **Display Name**（ボタンに出る名前）と、必要なら **Back Clip**（手の甲の音）を設定します。
4. **Tools > Silent Comfort > World Nadenade > Check Presets** で、Preset Id の空欄・重複や、音の付け忘れがないか確かめます。

### Prefab Variant で作る

配布されている `NadeSoundPreset_Base.prefab` を右クリック → **Create > Prefab Variant** で作り、音源・Display Name・Preset Id だけを上書きします。できた Variant を Presets の下に置きます。

上書きしていない調整値は Base から受け継ぐので、音色どうしの扱いがそろいます。追加音源パックの音色も、この形で作られています。

## Preset Id のルール

Preset Id は、音色を見分けるための保存用の名前です。他の人の音色を探すときや、Persistence で前回の音色を戻すときに使います。

- **ワールド内で重複させないでください。** `Check Presets` で確かめられます。
- **公開後は変えないでください。** 変えると、その音色を選んでいた人の選択が先頭の音色に戻ります。名前を変えたいときは Display Name だけを変えます。
- 英小文字・数字・`_`・`-` だけを使うのがおすすめです。
- `silentcomfort_` で始まる Id は、World Nadenade の音色用です。自作の音色には使わないでください。

ワールドを更新した直後などで、人によって音色の並びが違っていても、Preset Id で探すので同じ音色で鳴ります。相手の音色が自分のワールドに無いときは、先頭の音色で鳴ります。

## NadeSoundPreset の項目

| 項目 | 内容 | 初期値 |
|---|---|---|
| Preset Id | 保存用の名前（上のルール）。空欄ならオブジェクト名を使う | – |
| Display Name | 音色ボタンに出す名前。短めに | – |
| Palm Clip | 手のひらの音（必須）。0.5〜2秒程度の、継ぎ目のないループ | – |
| Back Clip | 手の甲の音（任意）。空欄か Palm と同じクリップなら、手の甲でも手のひらの音 | – |
| Gain | この音色の音量の補正。音源ごとの大きさの差をそろえる。試し聴きにも掛かる | 1 |
| Min Speed / Max Speed | 無音になる速さ / 最大音量になる速さ（身長 1.6m 換算の m/s） | 0.05 / 0.8 |
| Volume Attack / Release | 音量が上がる速さ / 下がる速さ（Release が小さいほど余韻が長い） | 20 / 8 |
| Speed Pitch | ON にすると、手が速いほどピッチが上がる | OFF |
| Pitch Reference Speed | ピッチが元のまま（1.0）になる速さ | 0.4 |
| Pitch Speed Exponent | 速さに対するピッチの上がり方（1 = 正比例、0.5 = 自然寄り） | 0.5 |
| Pitch Min / Max | ピッチの下限 / 上限 | 0.7 / 1.6 |
| Pitch Wobble Depth / Time | 手を折り返したときのピッチのゆらぎの幅と、戻るまでの時間 | 0.03 / 0.25 |
| Attack Amount / Rise / Decay | 手を折り返したときに上乗せする音量と、その立ち上がり・消えるまでの時間 | 0.5 / 0.012 / 0.09 |

- 値は**起動時に一度だけ**読み込みます。Build & Test 中にインスペクターで変えても反映されないので、変えたら再ビルドしてください。
- 手の速さのなめらかさ、折り返しの検出、手のひら / 手の甲の判定は、全音色で共通（NadeManager の設定）です。

### Speed Pitch の考え方

なでる音は、髪や布の細かい凹凸を手が次々に乗り越えることで出るので、もとの振動の高さは手の速さに比例します。ただし実際に聞こえる音には、手や頭の響き（速さでは変わらない）が混ざるため、高さの変わり方は正比例より緩やかです。初期値の Exponent 0.5（速さ 2 倍でピッチ約 1.41 倍）はその目安です。

- サラサラした雑音に近い音源は、Exponent を上げても自然です。
- 音程感や響きの強い音源は「早回し」に聞こえやすいので、Exponent を下げるか、Pitch Min / Max の幅を狭めます。

## 試し聴き

音色ボタンを押すと、その音色が**押した人にだけ**約2秒聞こえます。

- 手のひらと手の甲で別の音が入った音色は、**左から手のひらの音、右から手の甲の音**が聞こえます。それ以外は中央から1つだけ聞こえます。
- 音量は「聞こえる音」の音量と、音色の Gain に従います。
- なで音が OFF でも、壁のパネルからなら鳴ります。

試し聴きは WorldNadenade の子 `Preview`（NadePreview）が受け持ちます。`Preview` が無いときは、**Tools > Silent Comfort > World Nadenade > Add Preview Sources** で作れます。試し聴きが要らなければ `Preview` を削除してください。

| 項目（NadePreview） | 内容 | 初期値 |
|---|---|---|
| Preview On Select | オフにすると試し聴きしない | オン |
| Duration | 試し聴きの長さ（秒） | 2 |
| Volume | 試し聴きの音量 | 0.8 |
| Pan | 左右の振り分け（0 = 中央、1 = 完全に左右） | 0.8 |

## 音を鳴らしながら調整する（Sound Tuner）

音色の値を、**エディタ上で音を鳴らしながら**調整するツールです。再生モードやビルドは要りません。

1. 音色を選び、インスペクターの **「音を鳴らして調整する（Sound Tuner）」** を押します（**Tools > Silent Comfort > World Nadenade > Sound Tuner** からも開けます）。
2. **▶ 再生** を押すと、手が頭の上を往復する動きを計算で作って鳴らします。
3. 鳴らしたまま、手の速さ・往復の間隔と、音色の値を変えて聴き比べます。
4. 納得したら **適用** を押します。押すまで音色の値は変わりません（Undo で戻せます）。

ツールの音は 2D で、手の動きもぶれのない往復です。折り返しの量（Attack・Wobble）はツールで決め、折り返しの検出のしやすさは最後に VR で確かめてください。
