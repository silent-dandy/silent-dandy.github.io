Silent Comfort / ジェネレーター

なでなで・ASMR音ジェネレーター

撫で音・オイル・耳ふさぎ・耳かきなどの音を、ノイズと簡単な信号からブラウザの中で合成して、WAVに書き出すツールです。

使う前に

このツールを使うと、利用規約に同意したものとみなします。基本は「自由に使ってOK、ただし他の人の迷惑になることはNG」です。

  • 書き出した音は、個人・商用を問わず作品に組み込めます。クレジットは不要です
  • YouTube の Content ID などの照合サービスには登録しないでください
  • 書き出した音を加工せず、そのまま素材集として配布・販売するのはNGです
ジェネレーターを開く

できること

  • 8種類の音（撫で音、オイル・ぬるぬる、耳ふさぎ、耳かき、梵天、タッピング、吐息、パリパリ）
  • こもり、耳元の近さ、左右の位置（HRTF）、小さな部屋の響き
  • 音を時間に沿って並べるパターンと、ループ用の書き出し
  • VRChatワールドギミック「World Nadenade」用の音色素材の書き出し（取り込み方）

設定ファイルの例

保存して、ジェネレーターの「設定を読み込む」から読み込めます。

  • 肌なで・やわらか低め
  • 肌なで・オイル（こもった連続音）
最新の Chrome で動きます。iPhone では消音スイッチをオフにしてください。音はすべてお使いの端末の中で作られ、外部には送信されません。
